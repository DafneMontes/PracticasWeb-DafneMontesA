1. ¿Qué es Internet?

Internet es una red mundial que conecta millones de dispositivos y permite compartir información. Gracias a ella podemos navegar por páginas web, enviar mensajes, ver videos y comunicarnos con personas de diferentes lugares.

2. ¿Qué son los Proveedores de Internet?

Son empresas que ofrecen el servicio de conexión a Internet a las personas, hogares y negocios. Gracias a estos proveedores podemos acceder a páginas web, redes sociales y diferentes plataformas digitales.

3. Tipos de Proveedores de Internet

Existen diferentes formas de conectarse a Internet:

  • Fibra óptica: ofrece conexión rápida mediante cables.
  • DSL: utiliza líneas telefónicas.
  • Cable: utiliza cables de televisión.
  • Satelital: utiliza satélites para conectarse.
  • Inalámbrico: utiliza señales de radio.
  • Datos móviles: utiliza redes celulares.

4. Carpeta Local vs Carpeta Remota

Una carpeta local es aquella que se guarda directamente en nuestra computadora o dispositivo. Podemos abrir sus archivos sin necesidad de Internet.

Una carpeta remota se encuentra guardada en otro equipo o servidor y podemos acceder a ella mediante una conexión de red o Internet. Un ejemplo es Google Drive.

5. Experiencia de Usuario (UX) Vs Interfaz de Usuario (UI)

UX: significa experiencia de usuario y se relaciona con qué tan fácil y práctico es utilizar una página web o aplicación.

UI: significa interfaz de usuario y se enfoca en la parte visual, como los colores, botones, imágenes, letras y distribución de los elementos.

Ambos trabajan juntos para crear páginas atractivas y fáciles de utilizar.

6. ¿Qué es Maquetación Web?

La maquetación web consiste en organizar los elementos de una página de Internet, como los títulos, textos, imágenes, botones y menús. Su objetivo es que todo tenga un orden y sea fácil de entender.

Para realizarla se utilizan HTML para organizar el contenido y CSS para darle diseño y color.

7. ¿Qué es el Modelo de Cajas en HTML y CSS?

Es una forma en la que CSS organiza los elementos de una página web. Cada elemento se representa como una caja que tiene cuatro partes:

  • Content: es el contenido.
  • Padding: es el espacio interno.
  • Border: es el borde de la caja.
  • Margin: es el espacio exterior.

Sirve para controlar los tamaños y espacios de cada elemento y mantener ordenada la página.
